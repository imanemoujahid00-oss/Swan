## Verification

- Local: 44 tests and 29 subtests passed. Two expected personalisation tests remain documented limitations.
- Hosted HTTP: 51/51 checks passed, including all 31 regenerated synthetic profiles, authenticated readiness (50 products), strict invalid-type handling, future concerns, referral/out-of-scope outcomes, stable repeated ranking and fragrance avoidance.
- Browser: real public questionnaire → authenticated private API → actual product names/codes/reasons verified. Answer editing preserved the profile; selecting dryness showed the future-concern page; reset returned to welcome.
- Access: anonymous API request returned 403; API IAM explicitly grants invocation to the UI identity. Only the UI has public invocation access.
- No questionnaire database is implemented. Application code does not log request bodies; uvicorn access logging is disabled. Cloud platform request metadata and operational logs still exist.

During automated browser testing, changing the slider with an accessibility increment updated its displayed value without committing the form value. A normal pointer selection committed level 2 and the submitted journey passed. No scoring or questionnaire change was made for that automation issue.
